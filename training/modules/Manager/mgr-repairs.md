---slide---
## The rule: the route finishes today
- Every crew carries backups so a breakdown never pushes work to Saturday. {reveal}
- Two string trimmers, two blowers and an edger. A trimmer can edge if the edger dies. {reveal}
- When something breaks, swap to the backup first. Fix it later. {reveal}

---slide---
## When to fix it
- Fix it during downtime, or over lunch if you choose to. {reveal}
- The crew is never required to give up lunch for a repair. {reveal}
- Stop after 20 minutes. If it is not fixed, it goes to the shop. {reveal}
- Only you need to be the mechanic. The crew keeps working. {reveal}

---slide---
## What rides on the truck
- A full tool set. {reveal}
- Spare carburetors for the trimmers, edgers and blowers. {reveal}
- Spare mower spindles and belts. {reveal}
- Trimmer string, edger blades and spark plugs. {reveal}
- Weingartz is nearby for parts. {reveal}
note: Tell the operations manager when a spare is used so it is replaced.

---slide---
## Engine will not start
- Fuel fresh and mixed 50 to 1? Old or wrong fuel is the usual cause. {reveal}
- Prime and choke as set out in the Equipment module. {reveal}
- Pull the spark plug. Wet or fouled: clean or replace it. {reveal}
- Check the air filter. Clean it or swap it. {reveal}
- Still dead: swap the carburetor, or tag it for the shop. {reveal}

---slide---
## Engine runs but bogs
- Dirty air filter: clean or replace. {reveal}
- Clogged spark arrestor screen on the muffler: clean it. {reveal}
- Fuel filter in the tank clogged: replace it. {reveal}

---slide---
## Trimmers and edgers
- Reload trimmer string when it runs short. Keep a spare head loaded. {reveal}
- Check edger blades and replace a worn blade before the day starts. {reveal}
- The crew checks string and blades. You make sure spares are on the truck. {reveal}

---slide---
## Mowers
- Keep a spare sharpened set of blades on the truck. {reveal}
- Swap the mower blades once a week. {reveal}
- The dull set goes to the operations manager for sharpening. {reveal}
- A broken spindle or belt is a truck fix if it fits the 20-minute rule. {reveal}

---slide---
## A mower that will not run
- Do not lose the day on it. Finish the route with what runs. {reveal}
- Drop it at Weingartz for repair. {reveal}
- Call the operations manager. He gets a replacement so the crew is back out. {reveal}

---slide---
## Safety before any repair
- Engine off. Pull the spark plug wire on a mower before touching a blade. {reveal}
- Let a hot engine cool before you touch the muffler. {reveal}
- Never refuel a running or hot engine. {reveal}
